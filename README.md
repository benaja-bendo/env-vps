# VPS Dockerisé avec Traefik

Ce projet permet de déployer et gérer facilement des applications dockerisées sur un VPS avec Traefik en reverse proxy et HTTPS automatique.

## Documentation rapide  

- [Installation et configuration serveur](./docs/serveur-guide.md)
- [Logiciels utiles à installer](./docs/installation-logiciels-utiles.md)
- [Déploiement d'applications](./docs/apps/README.md)
- [Configuration spécifique des services](./docs/config-divers-apps.md)

## Structure du projet

- `opt/` : Contient la configuration de Traefik.
- `srv/` : Dossiers pour les applications et services Docker.
